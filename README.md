# Expense Tracker 💰

A simple Python program to record, view, and analyze your daily expenses.

## Features
- ➕ Add new expenses
- 📋 View all expenses
- 📊 Analyze spending by category

## How to Run
Open Command Prompt
You need to start the terminal where you’ll run commands.

Press Win + R → type cmd → Enter
This opens the Command Prompt window

02
Clone Your Repository
Download your GitHub project to your computer.
In Command Prompt, type:
bash
git clone https://github.com/Sirivennela-123/expenseTRACKER.git

03
Navigate to Project Folder
Move into the folder that contains your project files.

Type:
bash
cd expenseTRACKER

04
Check Python Installation
Make sure Python is installed and the version is correct.

Type:
bash
python --version
Should show Python 3.8 or higher

05
Run Your Program
Main Step
Execute the Python file to start your expense tracker.

Type:
bash
python main.py
If that doesn’t work, try:

bash
python3 main.py
